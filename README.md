# HOMEWARD

HOMEWARD — SVA Design for Good 2026 student prototype. Not an official NYC government service.

A guide that helps New York City residents worried about keeping their home explore housing support options and connect with official NYC help. It does not determine eligibility.

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

Static site: `index.html`, `explore.html`, `support.html`, `css/`, `js/`, `assets/`. No build step, no backend, nothing stored.

3D house: Microsoft Fluent Emoji (MIT License, see `assets/3d/FLUENT_EMOJI_LICENSE.txt`).
